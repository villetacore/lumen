# Спецификация формата Lumen

Версия: `0.1`. Обязательна к реализации и в Go (`server/internal/markdown`),
и в Rust (`desktop/core/src/md`). Обе реализации проходят одни и те же
golden-тесты из [`testdata/`](testdata).

## 1. Заметка

Файл `*.md` в UTF-8, LF или CRLF. Опциональный YAML frontmatter в начале файла:

```markdown
---
id: 01K5Q9V3JX8ZQ2N6C1B7M4TDA0
title: Запуск Lumen
type: project
tags: [work, lumen]
created: 2026-09-08T10:00:00+03:00
updated: 2026-09-08T12:31:11+03:00
status: active
---

# Запуск Lumen

- [ ] Написать спецификацию формата [due:: 2026-09-10] ^k5q9v3
```

### Поля frontmatter

| Поле | Тип | Обяз. | Смысл |
|---|---|---|---|
| `id` | ULID (26 симв.) | нет¹ | Стабильный идентификатор заметки |
| `title` | string | нет² | Заголовок |
| `type` | `note`\|`project`\|`area`\|`daily`\|`meeting`\|`event` | нет | Влияет на представления |
| `tags` | string[] | нет | Теги (без `#`) |
| `created` / `updated` | RFC3339 | нет | Времена |
| `status` | string | нет | Для `type: project` |
| `start` / `end` | RFC3339 или `YYYY-MM-DD` | нет | Делает заметку событием календаря |
| `allday` | bool | нет | Событие на весь день |
| `aliases` | string[] | нет | Доп. имена для `[[ссылок]]` |
| `source` | object | нет | Метка интеграции: `{connector, external_id, url}` |

¹ Если `id` нет, идентификатор заметки — её путь относительно корня vault.
`id` проставляется лениво, при первой записи в файл через API.
² Если `title` нет — берётся первый `# H1`, иначе имя файла без расширения.

Неизвестные поля frontmatter **сохраняются как есть** при записи.

## 2. Задача

Задача — строка-чекбокс в любой заметке, на любом уровне вложенности списка:

```
- [ ] Текст задачи #tag [due:: 2026-09-10] [prio:: A] ^blk1a2b
```

### Статусы

| Символ | Статус | Смысл |
|---|---|---|
| ` ` | `todo` | Не начата |
| `/` | `doing` | В работе |
| `x`, `X` | `done` | Выполнена |
| `-` | `cancelled` | Отменена |
| `>` | `deferred` | Перенесена |

Любой другой символ в скобках → статус `todo`, символ сохраняется при записи.

### Инлайн-поля

Синтаксис `[ключ:: значение]` (совместим с Dataview).

| Ключ | Значение | Пример |
|---|---|---|
| `due` | дата | `[due:: 2026-09-10]` |
| `scheduled` | дата | `[scheduled:: 2026-09-09]` |
| `start` | дата | `[start:: 2026-09-08]` |
| `done` | дата | `[done:: 2026-09-08]` |
| `prio` | `A`\|`B`\|`C`\|`D` | `[prio:: A]` |
| `est` | длительность | `[est:: 2h30m]` |
| `project` | wikilink или текст | `[project:: [[Запуск Lumen]]]` |
| `repeat` | RRULE-lite | `[repeat:: every week]` |
| `assignee` | текст | `[assignee:: alex]` |

Дата: `YYYY-MM-DD` либо `YYYY-MM-DDTHH:MM`. Относительные значения
(`today`, `tomorrow`, `завтра`, `+3d`) принимаются **на входе от UI** и
нормализуются в абсолютную дату перед записью в файл.

### Идентичность задачи

1. Если строка заканчивается на `^blockid` — это идентификатор задачи.
2. Иначе идентификатор вычисляемый и **нестабильный**:
   `sha1(relpath + "\n" + normalizedText)[:12]`, при коллизии добавляется порядковый номер.
3. При первой записи в задачу через API ей присваивается `^blockid`
   (6 символов base32 от ULID) — так ссылки становятся стабильными.

`blockid`: `^[a-z0-9]{3,32}$`, в конце строки, отделён пробелом.

### Вложенность

Задачи наследуют «родителя» по отступу списка. Родительская задача не считается
выполненной автоматически.

## 3. Ссылки и теги

- `[[Заметка]]`, `[[Заметка|алиас]]`, `[[Заметка#Заголовок]]`, `[[Заметка#^blockid]]`.
- Разрешение имени: точное совпадение `id` → путь → имя файла → `aliases`.
- `#tag`, `#вложенный/тег`. Не считается тегом внутри кода (`` ` ``), ссылок и `#` в начале строки (заголовок).

## 4. События календаря

Источники событий для календаря:
1. Frontmatter `start`/`end` в заметке (`type: event` или любой другой).
2. Задачи с `due` или `scheduled`.
3. Ежедневная заметка по имени файла `YYYY-MM-DD.md`.
4. Внешние ICS-подписки (не файлы, живут только в индексе).

## 5. Раскладка vault (соглашение, не требование)

```
vault/
├── 00-inbox/
├── 10-notes/
├── 20-projects/
├── 30-areas/
├── 40-daily/2026/2026-09-08.md
├── 50-meetings/
├── 90-archive/
├── _templates/
└── .lumen/
    ├── config.yaml      настройки vault (папка дневников, шаблоны, представления)
    └── cache/           индекс, не синхронизируется
```

Файлы и папки, начинающиеся с `.`, а также `.lumen/cache/`, из индекса исключены.

## 6. Правила записи (lossless)

- Изменение задачи затрагивает **только её строку**.
- Изменение frontmatter сохраняет порядок ключей и неизвестные поля.
- Не меняются: перенос строк (LF/CRLF определяется по файлу), финальный перевод строки,
  отступы, стиль маркеров списка.
- Запись атомарна: `tmp` в той же директории → `fsync` → `rename`.
