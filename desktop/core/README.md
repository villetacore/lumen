# lumen-core

Ядро десктопного клиента: формат файлов, обход vault, индекс и запросы.
Ту же логику будут использовать CLI и мобильный клиент, поэтому в UI её нет.

```bash
cargo test     # включая общие golden-фикстуры из ../../spec/testdata
cargo build
```

## Модули

| Модуль | Ответственность |
|---|---|
| `model` | Доменные типы: `Note`, `Task`, `Event`, `LDate` |
| `md` | Разбор и запись формата (spec/FORMAT.md), lossless-патчи строк |
| `vault` | Обход папки, чтение, атомарная запись |
| `index` | Индекс в памяти, запросы задач и событий, представления |
| `lib.rs` | `Workspace` — vault + индекс + операции над задачами |

## Соответствие Go-реализации

`md` — порт `server/internal/markdown`. Обе реализации обязаны проходить
одни и те же фикстуры, см. [ADR-0004](../../docs/adr/0004-two-parser-implementations.md).
Отличие одно и осознанное: вычисляемые (не `^blockid`) идентификаторы задач
считаются разными хэшами, поэтому они локальны и не участвуют в синхронизации.
