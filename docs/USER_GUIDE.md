# Работа с Lumen

## Задачи

«Сегодня» объединяет запланированные дела и быстрые действия. В боковом меню
есть входящие, неделя, просроченные, предстоящие, задачи без даты и выполненные.
Счётчики показывают данные вашего хранилища.

В быстром вводе можно указать приоритет и срок:

```text
Подготовить макет !A @завтра
Проверить документацию !B @пт
Обновить зависимости @+2w
```

Поддерживаются `@сегодня`, `@завтра`, `@послезавтра`, дни `@пн`…`@вс`,
`@неделя`, смещения `@+3d`, `@+2w`, `@+1m` и дата `@2026-11-01`.
Задача без даты из «Сегодня» планируется на сегодня; ввод из «Входящих»
попадает во входящую заметку.

Нажмите на задачу, чтобы открыть карточку: статус, срок, план, приоритет,
оценка, проект, подробное описание и материалы. Переключение чекбокса меняет
строку задачи в исходном Markdown, а не переформатирует весь документ.

## Проекты, заметки и документы

Новый проект создаётся кнопкой `+` у списка проектов. У него есть описание и
материалы: рабочие записи и документы. Материалы можно прикреплять и к задачам,
а внутри них создавать вложенные записи.

«Документация» собирает документы, «Материалы» позволяет просматривать записи.
Связи с родителем сохраняются в frontmatter. При удалении родителя вложенные
материалы не удаляются каскадно и остаются в общем списке.

Текст поддерживает заголовки, списки, код, ссылки, `[[ссылки на заметки]]`, теги
и чекбоксы. Несуществующую заметку можно создать по ссылке на неё. Сырые HTML-вставки
не исполняются. Редактор — текстовый Markdown, не WYSIWYG.

## Сохранение и конфликты

Нажмите «Редактировать» или дважды щёлкните по тексту заметки.
`Ctrl+S` / `Cmd+S` сохраняет изменения. При уходе с несохранённым текстом
Lumen просит подтвердить переход.

Если файл изменился снаружи, редактор показывает предупреждение и сохраняет ваш
черновик. Сначала сравните текст с версией на диске. Можно взять новую версию,
скопировать черновик или осознанно сохранить его поверх. Если файл удалён,
редактор предлагает создать его заново. Ошибка сети сама по себе не означает,
что сохранение прошло: дождитесь подтверждения.

Черновик защищён при обновлении данных внутри открытой страницы, но не является
отдельной резервной копией после закрытия вкладки или сбоя браузера. Сохраняйте
важный текст в файл. Удалённые заметки находятся в `.lumen/trash/` внутри vault.

## Поиск, календарь и тема

- `Ctrl+K` / `Cmd+K` переводит фокус в поиск. Ищите заметки и задачи по тексту.
- «Мой день» открывает дневную запись. «Календарь» показывает задачи и события
  подключённых календарей.
- Переключатель внизу бокового меню выбирает светлую, тёмную или системную тему.
  Настройка сохраняется в этом браузере.
- На телефоне боковое меню открывается кнопкой; `Escape` закрывает его и
  возвращает фокус. Переход в раздел также закрывает меню.

## Внешние сервисы

Подключения настраиваются в «Интеграциях». Используйте
[инструкцию коннекторов](INTEGRATIONS.md) и [ссылки на секреты](SECRETS.md).
Исходный сервис остаётся владельцем импортированного объекта.

В импортированных документах пишите свои дополнения **вне блока источника**:
они сохраняются при обновлении. Ручная правка внутри блока останавливает импорт
с ошибкой, чтобы не затереть изменения. UI разрешения таких конфликтов пока нет.

Раздел «Пароли» читает данные внешнего менеджера по запросу, а не заменяет его.
В стандартном контейнере CLI менеджеров отсутствуют; см. [ограничения](PASSWORDS.md).
