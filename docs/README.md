# Документация Lumen

Начните с установки или выберите руководство под свою задачу. Документы этого
раздела описывают текущий backend/web; каталог `plans/` содержит будущие изменения.

- [Руководство пользователя](USER_GUIDE.md) — задачи, проекты, документы, черновики и темы.
- [Интеграции](INTEGRATIONS.md) — календари, Nextcloud и импорт issues.
- [Пароли](PASSWORDS.md) — чтение записей из внешних менеджеров.
- [Решение проблем](TROUBLESHOOTING.md) — запуск, доступ, обновления и конфликты.
