# ADR-0001. Файлы Markdown — источник правды

**Статус:** принято · 2026-09-08

## Контекст
Нужно выбрать, где живут данные: в БД (а `.md` — формат экспорта) или в файлах
(а БД — индекс).

## Решение
Источник правды — папка `.md` файлов. Любая БД в системе является перестраиваемым
индексом и может быть удалена без потери данных.

## Последствия
**Плюсы:** переносимость, git, работа в Obsidian/любом редакторе, нет lock-in,
простое резервное копирование, доверие пользователя.
**Минусы:** сложнее транзакции и «сложные» поля; запись должна быть lossless;
нужен файловый watcher; парсинг дороже, чем SQL; уникальность id обеспечивается
приложением, а не БД.
**Митигация:** индекс в SQLite + FTS5, атомарная запись, golden-тесты парсера.

## Альтернативы
- **БД как истина, экспорт в md.** Проще технически, но теряется главная ценность.
- **Гибрид: md для контента, БД для метаданных.** Метаданные перестают быть видны
  в файле → расхождение между Obsidian и Lumen. Отклонено.
