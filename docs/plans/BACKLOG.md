# Задачи реализации

Начальный статус всех задач — **todo**; фактическое выполнение ведётся в
[PROGRESS.md](PROGRESS.md). Активная последовательность поставки — срезы A–G в
[инструкции реализации](IMPLEMENTATION_GUIDE.md), включая ранний агентный runtime.
P0 — целостность/доступ или обязательная
основа; P1 — основной продуктовый сценарий; P2 — расширение после пилота.
Приоритет не отменяет зависимости. Роли обозначают область ответственности,
а не назначенных людей. Критерии в последней колонке — условия закрытия задачи.

## Definition of done

Изменение закрывает пользовательский сценарий, имеет проверку нужного уровня,
документирует новый контракт и ограничения. Для хранения нужны миграция и restore;
для записи во внешний сервис — конфликт, повтор и неизвестный исход; для поиска
и AI — ACL, удаление и provenance. Обновлены связанные документы и status функций.
Тесты запускаются на фикстурах/тестовых сервисах, не на боевых данных пользователя.
