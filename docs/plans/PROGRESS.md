## Формат записи выполненной работы

Для каждой взятой задачи добавить запись:

```text
ID / дата / статус: todo | in_progress | partial | blocked | done
Изменённое поведение и файлы:
Проверки: команда, результат; для ручной проверки — шаги и наблюдение
Миграция/совместимость (если затронуты):
Невыполненные критерии или blocker:
Следующая задача и причина выбора:
```

Не отмечать задачи выполненными по самому наличию этих документов. Не хранить
здесь credentials, содержимое закрытых источников или полные логи пользователя.
