# План документации

Продуктовый приоритет уточнён: [AI-центр управления студией](PRODUCT_DIRECTION.md).
Уже подготовлены [runtime](AGENT_RUNTIME.md), [инструкция кодирующему агенту](IMPLEMENTATION_GUIDE.md)
и [журнал прогресса](PROGRESS.md); они являются проектными документами, не реализацией.

Этот пакет описывает направление и задачи. Следующие документы нужно довести до
реализуемых контрактов и поддерживать вместе с соответствующими изменениями кода.

## ADR для принятия перед реализацией

Номера предварительные, выбирать свободные при создании. Статус сначала proposed.

- ADR-0010: модульный монолит и общие use cases для HTTP/MCP/jobs.
- ADR-0011: оригиналы контента, внешнее владение и обязательная операционная БД;
  явно уточняет область ADR-0001, сохраняет файловый контент.
- ADR-0012: SQLite single-instance, условия перехода к PostgreSQL.
- ADR-0013: capabilities коннекторов, устойчивые действия и подтверждения.
- ADR-0014: search backend по benchmark, chunk/embedding versioning.
- ADR-0015: MCP server/client, границы доверия и протокольная версия.
- ADR-0016: политика AI-провайдеров, разрешённые данные и хранение истории.
- ADR-0017: самостоятельный Lumen runtime, один последовательный агент,
  sessions/runs/artifacts и восстановление; OpenClaw — ориентир, не зависимость.
- ADR-0018: версии сценариев, память по областям и автоматизации от имени владельца.

Для каждого ADR: контекст, выбранное решение, рассмотренные альтернативы,
последствия, критерий пересмотра и миграция. Не объявлять выбор принятым только
потому, что он упомянут в плане.

## Правила актуальности

У документа есть status (`implemented`, `proposed`, `deprecated`), дата проверки
и ссылка на код/задачу. Примеры API должны соответствовать контрактным фикстурам.
Изменение контракта включает документацию в тот же PR. Секреты и реальные токены
в примеры не попадают. Проверка локальных ссылок и генерации API запускается в CI.

Текущий пакет основан на чтении репозитория 2026-10-14; тесты приложения в рамках
подготовки плана не запускались. Ссылки на официальные внешние материалы находятся
в [AI/MCP/RAG](AI_MCP_RAG.md); перед реализацией закрепляются версии зависимостей
и спецификаций вместо плавающего `latest`.
