# MVP: границы

Цель MVP — «я могу вести свои задачи и заметки в Lumen вместо Obsidian+плагинов,
на десктопе и в вебе, с одной синхронизируемой папкой».

## Что входит в MVP (M1–M2)

### Vault и заметки
- Открыть локальную папку как vault; рекурсивный обход `.md`.
- Просмотр и редактирование заметки (Markdown, split-preview).
- YAML frontmatter: `id`, `title`, `tags`, `type`, `created`, `updated`.
- `[[wikilinks]]` с автодополнением, `#tags`, backlinks-панель.
- Ежедневные заметки (`40-daily/2026/2026-09-08.md`) по шаблону.
- Полнотекстовый поиск + поиск по тегам.

### Задачи
- Задача = строка-чекбокс в любой заметке: `- [ ] Текст [due:: 2026-09-10] ^id`.
- Статусы: `todo / doing / done / cancelled`.
- Инлайн-поля: `due`, `scheduled`, `prio`, `est`, `project`, `repeat` (M2).
- Представления: **Inbox**, **Сегодня**, **Неделя**, **Все задачи**, **Kanban по статусу**,
  **по проекту**. Все представления — это сохранённые запросы, а не отдельная сущность.
- Изменение задачи (галочка, дата, приоритет) пишет обратно в исходный `.md` файл,
  меняя только целевую строку.

### Календарь
- Месяц / неделя / день.
- На календаре: задачи с `due`/`scheduled`, события из frontmatter (`start`/`end`),
  ежедневные заметки.
- Drag-n-drop задачи по дням → перезапись `scheduled` в файле.

### Синхронизация
- Клиент ⇄ сервер, по файлам, с версионированием и определением конфликтов.
- Конфликт не теряет данные: создаётся `Note (conflict 2026-09-08 10-31).md`.

### Интеграции (в MVP — одна, каркас — под все)
- **ICS-подписка** (Google/Outlook/Яндекс календарь read-only) → события в календаре.
- Каркас коннекторов, планировщик, хранение конфигов и токенов — готовы под остальные.

### Платформы
- Веб-клиент (React) — полный набор функций поверх сервера.
- Десктоп (Flutter + Rust) — работа с локальным vault офлайн, синхронизация с сервером.

## Что НЕ входит в MVP

- Совместное редактирование в реальном времени, CRDT, мультипользовательские команды.
- Мобильные приложения.
- Плагины/скрипты пользователя.
- Граф связей (визуальный), канвас, embed-запросы внутри заметок.
- Двусторонняя синхронизация с внешними трекерами (только чтение на M3).
- Шифрование vault на стороне клиента (E2EE) — вынесено в M4.

## Пользовательские сценарии (acceptance)

1. Указываю папку → вижу дерево заметок и список задач за 1 сек на 5 000 файлов.
2. Пишу `- [ ] Позвонить в банк [due:: завтра]` в дневной заметке → задача появляется
   в «Сегодня» и на календаре.
3. Ставлю галочку в веб-клиенте → строка в `.md` файле становится
   `- [x] ... [done:: 2026-09-08]`, десктоп подхватывает изменение после sync.
4. Перетаскиваю задачу на другой день в календаре → в файле обновляется `scheduled`.
5. Редактирую один и тот же файл офлайн на двух устройствах → после sync вижу
   обе версии, ни одна не потеряна.
6. Подключаю ICS-ссылку рабочего календаря → встречи видны рядом с задачами.
