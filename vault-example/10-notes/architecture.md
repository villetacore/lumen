# Архитектура Lumen

Файлы — источник правды, БД — индекс. Подробности в [[Запуск Lumen]].

Три клиента, один формат:

1. Веб — тонкий клиент к серверу.
2. Десктоп — офлайн, ядро на Rust.
3. Сервер — синхронизация и #интеграции.

Пример разметки внутри кода не должен индексироваться: `- [ ] не задача #нетег`.
