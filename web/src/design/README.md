# Velessoft RIOT v0.3 в Lumen

Источник — переданный владельцем `velessoft-punk.zip` (01.11.2026).
`velessoft-punk.tokens.json` — неизменённый `tokens.json` из пакета.

В `../styles.css` перенесены обе семантические палитры, нулевые радиусы,
Manrope для текста и JetBrains Mono для навигации/меток. Шрифты и лицензии
из архива находятся в `../../public/fonts/`; загрузок с CDN нет.
Lucide используется через существующий компонент `Icon` (stroke 2).

Рабочие экраны следуют продуктовому варианту из `index.html#projects`:
нейтральные поверхности, квадратные рамки, ровные формы и таблицы,
лайм для главного действия, фиолетовый для выбранной области.
В `tokens.json` явно заданы `productShadow: none` и `productRotation: 0deg`.
Плакатные наклоны, жёсткие тени маркетинговых кнопок и старые растровые
концепты из архива в рабочие формы не перенесены.

Короткая шапка «Сегодня» применяет display 64/40 px, 800, 1.08;
остальные заголовки экранов — 40/30 px. Длинный контент остаётся обычного
регистра. Размер текста полей — 16 px, кнопки — минимум 44 px,
видимый фокус — 3 px. Брэкпоинты: 640/960/1280 px.

Lumen сохраняет собственное имя и знак; подпись VS / by velessoft связывает
его со студией. Структура рабочих экранов адаптирована к существующим
сценариям Lumen: пакет не содержит их отдельных макетов.
