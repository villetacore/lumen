# Веб-клиент Lumen

React 19 + TypeScript + Vite. Тонкий клиент к `lumend`.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173, /api проксируется на 127.0.0.1:8787
```

Другой адрес сервера: `LUMEN_API=http://host:port npm run dev`.

## Команды

```bash
npm run build        # tsc -b && vite build
npm run typecheck
npm test             # UI-проверки сохранности draft (Vitest + jsdom)
```

## Устройство

```
src/
├── api/client.ts        типизированный клиент + подписка на SSE
├── api/types.ts         DTO, зеркалящие server/internal/domain
├── hooks/               live-обновления
├── lib/date.ts          форматирование дат и недель
├── lib/errors.ts        понятные тексты ошибок API, 409/404
├── components/          TopBar, Sidebar, TaskRow (+редактор), QuickAdd, AsidePanel,
│                        Markdown (безопасный рендер), NewNoteDialog, CrashScreen
└── pages/               Tasks, Calendar, Notes, Note, Search
```

Данные — TanStack Query; изменения файлов на диске приходят по SSE
(`/api/v1/events`) и инвалидируют кэш, поэтому правка в Obsidian видна без
перезагрузки.

## Проекты, задачи и документация

Проект содержит подробное описание и раздел «Материалы». К нему можно добавлять
рабочие записи и документы; у них также могут быть вложенные материалы. По
щелчку на задаче открывается её карточка с параметрами, подробным описанием и
собственными материалами. Раздел «Документация» собирает все созданные документы.
Файловые пути назначаются автоматически; технические свойства скрыты в
раскрываемом разделе. Текст документов поддерживает Markdown.

`npm test` проверяет сохранность текста документа и описания задачи при refetch,
конфликте и попытке ухода со страницы. При удалении родителя его материалы
сохраняются и остаются доступны в общем списке.
